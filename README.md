# Titanic Dataset – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Microsoft Excel. The main objective is to understand passenger information and identify patterns through summary statistics and charts.

## Tools Used
- Microsoft Excel

## Dataset Information
- Total Passengers: 891
- Total Columns: 12
- Survivors: 342
- Non-Survivors: 549
- Survival Rate: 38.38%

## Analysis Performed
- Total passengers and columns
- Survival count and survival rate
- Average, minimum, and maximum passenger age
- Average ticket fare
- Key findings and data insights

## Charts Created
1. Titanic Passenger Survival Status
2. Titanic Survival by Gender
3. Titanic Survival by Passenger Class
4. Titanic Passenger Age Distribution
5. Titanic Passenger Fare Distribution

## Key Findings
- Out of 891 passengers, 342 survived.
- Female passengers had a higher survival count (233) than male passengers (109).
- First-class passengers had the highest number of survivors (136).
- The average passenger age was approximately 29.36 years.
- The average ticket fare was approximately 32.20.
- Age information was available for 886 passengers in the age distribution analysis; 5 passengers had missing age values.
- Age information was available for 886 passengers; 5 passengers had missing age values.
